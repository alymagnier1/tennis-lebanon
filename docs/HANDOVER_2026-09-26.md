## Gotchas on this machine — read before running anything

- **Avast HTTPS scanning** re-signs TLS. Node CLIs (eas-cli, npx) fail with `unable to verify the first certificate`. `%USERPROFILE%\windows-root-ca.pem` is **stale** (Avast regenerated its root after 09-17). Export the current root from `Cert:\LocalMachine\Root` (subject _Avast Web/Mail Shield Root_) to a PEM and set `NODE_EXTRA_CA_CERTS` to it. Git uses schannel and is fine. Large EAS uploads sometimes reset mid-way — retry once.
- **Publishing an `eas update` safely** (checklist §4, follow exactly): updates do **not** read `eas.json` build-profile env and **do** read local `.env` files. Export with `EXPO_NO_DOTENV=1`, the `build.staging.env` values set explicitly (or via `eas env:exec preview`), and **`--clear`** — without it Metro reused a bundle with the old key inlined. Inspect the `.hbc` (staging URL and `sb_publishable_` present; no `eyJ…` JWT, no `127.0.0.1`), then `eas update --skip-bundler --input-dir dist --channel staging --platform android --environment preview`.
- **Local `.env` files point at staging.** `apps/mobile/.env.local.off` is the local-DB variant; copy it to `.env.local` only temporarily and delete it before any export.
- **A local tool rewrites working-tree files with CRLF** (seen 09-22 20:59, 09-25 01:47). No content change; `.gitattributes` normalises on commit. `pnpm format` clears it. It also once left a stale `.git/index.lock`.
- **Git Bash mangles `/data`-style paths** passed to `adb shell` — set `MSYS_NO_PATHCONV=1`.
- **Prettier is non-idempotent** on inline code wrapped across lines inside Markdown list items. Keep each command on one line.
- **Never** paste or log keys. Never type passwords into forms on the testers' behalf. Never edit an applied migration — add a new one (latest is 108).
- Repo auto-merge is disabled on GitHub; merge PRs after all 4 checks pass (Lint/typecheck/unit, Supabase migration smoke test, Vercel, Vercel Preview Comments).
