The direction
Broadcast scoreboard. Archivo at its widest, uppercase, for facts the app knows — date, time, level, distance. Outfit italic only for words a person typed, so a request note reads as a human voice against the data.
Lime is structure, not decoration. A 2px lime rule opens the plate and the requests group; a 1px grey rule separates everything quiet. Card-in-card nesting is gone — two surfaces on the whole screen.
Approve is lime, not purple. The one filled control on the sheet, full width with Reject reduced to a bordered glyph. Accepting someone and rejecting them should not be the same size.
Ordinals do double duty. 01–04 numbers the line-up, 01–02 the request queue, 01–03 the court ranking. One device, three lists, no extra labels like “first choice”.
Radius drops to 3px. Squared avatars and controls read as a printed sheet. This departs from tennisRadii — if it survives, it needs a token.

What changed
Same skeleton, fewer groups. Requests and “You invited” are absent, not disabled — a decline is private between the player and whoever invited them. The people card keeps its shell and shows one group, “Players”, so the screen reads as the same object with less to manage.
The strip states standing, then the ask. “You are in · two seats left”, and it names where an invite goes so a non-host is not surprised that Karim approves it.
The time row becomes the answer point. “Change” becomes “Answer” — a participant accepts or counters rather than sets. The ⋯ menu holds a single item, Leave match.
Where the cut material went
The More drawer, reduced
The header ⋯ now holds exactly what the screen no longer shows inline: extend listing, match details, release court, cancel match, leave match. The duplicate invite and proposed-times entries are gone; participants is gone because the seat strip and the Players group already are it.
Destructive actions, gathered
One exception stays inline: per-row Withdraw, because it is scoped to a person and reversible. Everything that ends the match sits in the ⋯ menu behind a confirmation, so no red link shares a screen with an Approve button.
Preferred clubs, deferred
The map tile was answering a booking question in a state where booking is not the job. The row keeps the one fact that matters now — not booked — and the map lives on the club screen, one tap away, where it is the point.
RTL and type
Every row is a flex row with gap and a flexible middle, so mirroring is a direction change with no left or right assumptions. Status pills wrap as a unit; the longest string here, “On hold — match full”, has room for roughly 20% Arabic growth before it wraps to two lines, which it may.
